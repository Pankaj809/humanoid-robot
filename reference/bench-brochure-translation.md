# Humanoid Robot Experimental Platform (人形机器人实验台) — English rendering

**Source:** the vendor brochure (6 pages, Chinese), Unitree Robotics Co., Ltd. (宇树科技股份有限公司).
The PDF itself is kept locally and is not redistributed in this repository.
**Product:** Humanoid Robot Platform / Humanoid Robot Experimental Platform (人形机器人实验台)
**Model:** SXT-LK-R1-1 (SXT-LK-R1-1型)

This is a complete translation of the brochure, organised as the brochure is. Marketing
slogans are rendered plainly. Where the original uses lab/engineering jargon, the Chinese
term is given in parentheses on first appearance.

> **Reading the `[*]` marks.** The brochure uses `[*]` twice, with two different footnotes:
> - On equipment: *"[*] 本产品不包含该设备（需额外购买）"* — **this product does not include
>   this item; it must be purchased separately.**
> - On the course systems: *"[*] 本产品不包含该课程体系，需单独购买。"* — **this product does not
>   include this curriculum; it must be purchased separately.**
>
> Every `[*]` item is called out explicitly below and collected in the summary at the end.

## 5. Curriculum System (课程体系 / Curriculum System)

Two courses are offered. **Both are marked `[*]`: "This product does not include this
curriculum; it must be purchased separately." (本产品不包含该课程体系，需单独购买。)**

### 5.1 *Humanoid Robot System Safety and Operations & Maintenance* (《人形机器人系统安全与运维》) **[*] NOT INCLUDED**

- Recommended teaching hours (建议学时): **64 hours**
- Recommended credits (建议学分): **4 credits**
- Supporting hardware platform (配套硬件平台): R1 humanoid robot, Humanoid Robot Experimental
  Platform

**Course objectives (课程目标):**

1. Master the core technical system of humanoid robot system safety and operations &
   maintenance (运维), and be capable of independently completing related development tasks.
2. Train students in humanoid robot system safety operation/maintenance and fault diagnosis,
   so that they can judge software and hardware faults in the basic modules, effectively
   handle abnormal situations, and perform log management.

**Course modules (课程模块) and contents (模块内容):**

| # | Module | Contents |
|---|---|---|
| 1 | System safety architecture and deployment standards (系统安全架构与部署规范) | Hoisting/suspension protection (吊装保护); emergency-stop button layout; work-area isolation; software safety boundaries; pre-deployment safety checklist |
| 2 | Sensor fault diagnosis (传感器故障诊断) | LiDAR data anomaly detection; depth camera disconnection; IMU drift identification; multi-sensor consistency verification |
| 3 | Communication safety and interference resistance (通信安全与抗干扰) | DDS communication configuration; handling Bluetooth / network channel congestion; safe-handling mechanisms after a communication interruption |
| 4 | Motion anomaly detection and emergency recovery (运动异常检测与应急恢复) | Joint position discontinuity ("sudden jump") detection; motion boundary over-limit checking; fall detection and posture recovery; emergency-stop response time measurement |
| 5 | Log management and problem reproduction (日志管理与问题复现) | Log-level/grading strategy; log writing and storage; automatic log upload; root-cause analysis |
| 6 | System and performance monitoring (系统与性能监控) | Motor temperature monitoring; performance baseline establishment; battery voltage and robot-body performance assessment |
| 7 | Version management (版本管理) | Humanoid robot OTA update and firmware version management; rollback strategy |

### 5.2 *Humanoid Robot Experimental Platform Course* (《人形机器人实验台课程》) **[*] NOT INCLUDED**

- Recommended teaching hours: **64 hours**
- Recommended credits: **4 credits**
- Supporting hardware platform: R1 humanoid robot, Humanoid Robot Experimental Platform

**Course objectives:**

1. Master the core technical system of the Humanoid Robot Experimental Platform course, and
   be capable of independently completing related development tasks.
2. Use the platform's rich interfaces and modules to develop students' understanding of, and
   ability to operate, the humanoid robot's low-level hardware system (底层硬件系统).

**Course modules and contents:**

| # | Module | Contents |
|---|---|---|
| 1 | System deconstruction and kinematics fundamentals (系统解构与运动学基础) | R1 humanoid robot mechanical hierarchy; joint parameters; degree-of-freedom configuration and kinematics fundamentals |
| 2 | Permanent-magnet synchronous motor FOC low-level control (永磁同步电机 FOC 底层控制) | Rotating magnetic field principle (旋转磁场原理); dual-encoder characteristics (双编码器特性); gear-reduction-ratio conversion (减速比换算); motor ID and serial communication (电机ID与串口通信) |
| 3 | Basic motion control (基础运动控制) | R1 SDK High/Low Level interface configuration; standing / walking / posture adjustment; DDS communication |
| 4 | Custom motion design and upper-body control (自定义动作设计与上半身控制) | Joint de-torquing / damping release (关节卸力); reading shutdown-state snapshots and saving motion files (关机状态快照读取及动作文件保存); upper-body control design and verification |
| 5 | End-effector gripper basic control (末端夹爪基础控制) | **Dex1-1 gripper** DDS communication; position / velocity / torque control; implementing gripper control both on the robot body and on the training bench |
| 6 | Sensor data acquisition and calibration (传感器数据读取与标定) | IMU data reading and parsing; LiDAR point-cloud acquisition and noise-point filtering |
| 7 | LiDAR perception and autonomous navigation (激光雷达感知与自主导航) | **Livox Mid-360** point-cloud visualisation; SLAM mapping; pose initialisation and navigation |
| 8 | Integrated course design / capstone (综合课程设计) | Build a humanoid robot autonomous grasping system project based on the **ACT model** and the vision module, realising the full pipeline from vision → ACT imitation learning → gripper manipulation (实现从视觉到ACT模仿学习到夹爪操作全流程) |
